## Built for agent frontends

nimterm gives you the terminal UI layer for apps that drive an agent: coding
assistants, chat clients, task runners, and long-running sessions. The widget
set follows that focus. You get streamed transcripts, tool call and approval
prompts, diffs, text input, menus, and multiple-choice questions, plus an agent
lifecycle vocabulary you can adapt any event source to.

It is a terminal UI library, not a general-purpose widget toolkit. There are no
tables, trees, tabs, or form builders. If you are rendering agent output and
collecting the occasional decision, nimterm covers the whole path from events to
terminal cells.
